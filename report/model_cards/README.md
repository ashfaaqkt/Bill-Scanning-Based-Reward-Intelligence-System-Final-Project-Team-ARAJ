## Reading these honestly

Three things are stated in the cards and worth repeating up front, because they
are the questions a viva panel will ask:

1. **The anomaly detector's 13.2% false-positive rate is *set*, not discovered.**
   It follows directly from the `contamination` parameter. Its recall is measured
   against *injected synthetic* outliers because no labelled real anomalies
   exist. Neither number means anything alone.

2. **The fraud CNN's headline 0.805 includes synthetic tampering.** 77% of the
   tampered class was generated by our own script. **0.864, measured on the 94
   real photographs, is the honest estimate of real-world performance.**

3. **The recommender's NDCG is not claimed against its target.** The hybrid is
   built, integrated and runs — an SVD factorisation blended with content-based
   affinity — and it scores NDCG@5 0.7984 offline. But it is trained *and*
   evaluated on generated interactions, where the relevance labels derive from
   the same rule that produced the training ratings. The score measures the
   generator, not the ranker, so the target stays open until real interaction
   logs exist.

## Not machine learning

For completeness, since the pipeline mixes them: **perceptual-hash duplicate
detection** (`fraud.py:is_duplicate_hash`) is a deterministic algorithm, not a
learned model, and the **OCR pipeline** is a prompted Gemini call plus classical
CV checks (contrast-normalised sharpness gate, density anomaly).

4. **Two integration seams were dead while every component test passed.** The
   tamper CNN was never given the image on an upload, and no perceptual hash was
   ever stored or sent, so the duplicate check returned false from the day it was
   written. Both were found and fixed on 19 Aug, and both are the same lesson:
   a green unit test says nothing about whether the caller passes the argument.
   Component-level results in these cards were never affected — they were
   measured directly, not through the API — but the *system* did not behave as
   the cards described until those fixes landed.
